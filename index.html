Vanya Pi Assistant

Vanya Pi Assistant is a private, personal assistant that runs on its owner's own Raspberry Pi. It is not a public service: only the owner uses it, and only the owner's Google account is connected.

With the owner's consent, the assistant uses Google APIs to:

  • read and search the owner's Gmail (read-only, it cannot send, delete or modify mail);
  • find, read and edit files in the owner's Google Drive and Google Docs;
  • access only those Google Photos items the owner explicitly selects in the Google Photos Picker.

The assistant does all of this only to carry out the owner's own requests and automations.
